1. Web API — это интерфейс, через который приложения обмениваются данными по HTTP.
2. [ApiController] — указывает, что класс является API-контроллером и автоматически обрабатывает запросы и ошибки валидации.
3. [Route] — задаёт адрес (маршрут), по которому можно обратиться к контроллеру или его методу.
4. GET — получает данные. POST — создаёт или добавляет новые данные.
5. PUT — изменяет существующие данные. DELETE — удаляет данные.
6. HTTP-коды:
    200 OK — запрос успешно выполнен.
    201 Created — объект успешно создан.
    400 Bad Request — некорректный запрос или данные.
    404 Not Found — объект или ресурс не найден.
